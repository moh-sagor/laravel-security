# Contributing to Laravel Security Firewall

Thank you for considering contributing to **Laravel Security Firewall (`sagor/laravel-security`)**!

## Development Setup

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/moh-sagor/laravel-security.git
   cd laravel-security
   ```

2. Install composer dependencies:
   ```bash
   composer install
   ```

3. Run automated unit and feature test suite:
   ```bash
   composer test
   ```

4. Run static analysis:
   ```bash
   composer analyse
   ```

## Coding Standards

* Strict PHP 7.2 to 8.4 syntax compatibility.
* Use `@param` and `@return` PHPDoc annotations.
* Follow PSR-12 coding standard conventions.
* Include comprehensive tests for all new rules or bug fixes.
