# Security Policy

## Reporting Vulnerabilities

If you discover a potential security vulnerability within **Laravel Security Firewall (`sagor/laravel-security`)**, please do **NOT** open a public issue on GitHub.

Instead, please report the vulnerability directly to our security maintainers via email at:

**security@example.com**

### What to Include in Your Report

* Detailed description of the potential vulnerability
* Steps or proof-of-concept (PoC) code to reproduce the issue safely
* The affected package version and PHP/Laravel environment details
* Any potential mitigation steps or patch suggestions

### Our Security Response Process

1. **Acknowledgement**: We will acknowledge receipt of your vulnerability report within 48 hours.
2. **Investigation**: Our team will investigate and confirm the vulnerability.
3. **Patch & Advisory**: Once confirmed, a fix will be developed, tested, and released as a security patch release.
4. **Disclosure**: A security release announcement will be issued with full credit given to the reporter.

Thank you for responsibly disclosing security vulnerabilities!
